# Список крупных задач по системам

Задачи собраны из двух ADR:
- **ADR-3** — открытие депозитов онлайн, MVP ([Task3/ADR.md](../Task3/ADR.md));
- **ADR-4** — передача ставок в кол-центр банка и партнёрский кол-центр ([Task4/ADR.md](ADR.md)).

Горизонт — 12 месяцев (М1–М12): **MVP** — М1–М6, **целевое состояние** — М7–М12. Колонка «Зависит от» задаёт последовательность работ для RoadMap ([roadmap.drawio](roadmap.drawio)).

## Ключевая последовательность

1. **Сначала источник и транспорт.** Модуль ставок в АБС (T1) и Kafka (T20) не зависят ни от чего, а от них зависит всё остальное.
2. **Затем публикация ставок** (T2 → T3). После этого параллельно стартуют все получатели: интернет-банк (T15), система КЦ (T12), сервис выгрузки для партнёра (T9).
3. **Ставки в кол-центрах — до запуска маркетинговой кампании.** КЦ банка (T12) и партнёрский КЦ (T27, T28) должны быть готовы раньше, чем клиенты начнут массово звонить после кампании (T31).
4. **Заявки — после ставок.** Онлайн-заявки (T5, T6, T16) имеют смысл только тогда, когда клиент видит ставки.
5. **Целевое состояние** (T7, T8, T14, T19) строится на готовом MVP без переделки архитектуры.
